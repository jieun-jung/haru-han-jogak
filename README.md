# 하루 한 조각

하루에 한 가지 순간을 기록하고, 달력과 목록으로 돌아보는 작은 기록장입니다. 기록은 별도 계정이나 서버 없이 현재 브라우저의 `localStorage`에 보관됩니다.

## 시작하기

`index.html`을 브라우저에서 열거나 간단한 정적 서버를 실행하세요.

```sh
python3 -m http.server 8000
```

그다음 `http://localhost:8000`을 엽니다. 외부 패키지 설치나 빌드 과정은 필요하지 않습니다.

## 기능

- 한 줄 기록, 질문 답변, 기분 기록 중 하루 하나 작성
- 오늘 기록 수정 및 삭제
- 기록 날짜를 표시하는 달력과 날짜별 미리보기
- 종류별 필터가 있는 기록 목록
- 모바일 화면 지원

브라우저 데이터나 사이트 저장 공간을 지우면 기록도 삭제됩니다. 이 버전은 브라우저 간 동기화를 제공하지 않습니다.
